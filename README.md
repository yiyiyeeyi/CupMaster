# CupMaster

CupMaster is a mobile-first AI pour-over coffee coach PWA. It helps people start a brew immediately with recipe defaults, follow clear guidance, save the cup, and improve later.

## Development

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

Open `http://localhost:3000`. Current routes are `/`, `/onboarding`, `/discover`, `/brew`, `/journal`, and `/me`. This round includes only a runnable shell, domain contracts, and specifications—no complete vertical slice, persistence, Supabase, AI API, camera, OCR, or AR.

Start with [product architecture](docs/product-architecture.md) and [vertical slices](docs/vertical-slices.md).
