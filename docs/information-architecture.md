# Information Architecture

Bottom navigation contains **Discover**, **Brew**, and **Journal**. The current shell also exposes **Me** as the profile entry; Collection and Gear are not first-level destinations.

Me contains Profile, My Gear, Gear Guide, My Library, Saved Recipes, Saved Beans, Suggested Plans, AI Preferences, and Settings. Collection remains available within My Library. Gear Guide (education and selection) and My Gear (owned/used equipment) remain separate concepts.

Product capabilities map to Start, Guide, Reflect, Remember, and Equip. A user can enter Brew without completing Remember or Equip data.
