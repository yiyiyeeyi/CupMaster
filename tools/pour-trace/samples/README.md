# 4:6 method trace sample

`4-6-method.json` is derived point data for a five-pour educational path, manually marked against sampled frames from the local screen recording supplied by yiyi on 2026-11-05. Its source URL is unknown and redistribution permission was not granted. The video, frames, sound, subtitles, and branding are not included in this repository.

The recording shows cumulative targets of 50 g, 120 g, 180 g, 240 g, and 300 g. Coordinates are marked from visible 0.5-second review frames and interpolated to 0.1-second output intervals. The kettle and hand hide some landing points, so those intervals are estimates. The sample is an educational visual trace, not a frame-by-frame measurement. Review it with the local annotator before presenting it as a faithful reproduction.
